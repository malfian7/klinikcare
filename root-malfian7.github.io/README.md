# malfian7.github.io (akar domain)

Repository ini hanya berisi file untuk akar domain `https://malfian7.github.io/`:

- `robots.txt`: mengizinkan mesin pencari dan menunjukkan lokasi sitemap.
- `sitemap.xml`: daftar halaman, berisi `https://malfian7.github.io/klinikcare/`.

Cara pasang: buat repository publik bernama persis `malfian7.github.io`, unggah file-file ini ke branch `main`, lalu buka **Settings → Pages** dan pilih branch `main`, folder `/ (root)`.
